# 【導入事例】Salesforce Sales Cloud から HubSpot へ、55万件を欠落ゼロで移行

**契約満了というタイムリミットのなか、55万件超・34.8億円分の営業データを1件も失わず移行。分断されていたマーケティングと営業を一つの基盤に統合し、「非エンジニアでも使える」CRMを約2ヶ月で実現**

3つの事業を展開するBtoB SaaS企業さま。Salesforceの契約満了が迫るなか、HubSpotへの全面的な乗せ替えをご支援しました。最大の山場は55万件を超えるデータの移行。なかでも34.8億円分の売上データを1件の欠落もなく移しきり、現場が自分たちで回せるCRMへと生まれ変わりました。

## 数値ハイライト

| 指標 | 成果 |
|------|------|
| 総移行件数 | **55万件超を欠落ゼロで移行** |
| 最難関のMRRデータ | **31,408件・34.8億円を1件も失わず移行** |
| メール履歴 | **42万件超を重複ゼロで移行** |
| 移行精度 | **移行後に独自検証で完全一致を確認** |

## お客様プロフィール

| 項目 | 内容 |
|------|------|
| 業種 | BtoB SaaS（3事業を展開） |
| 規模 | 営業20〜30名規模 |
| 移行前ツール | Salesforce Sales Cloud ＋ MA ＋ 別のメール配信ツール |
| 移行後ツール | HubSpot Sales Hub ＋ Marketing Hub Professional |

## 課題（Before）

ご相談をいただいた時点で、お客様は次のような状況にありました。

1. **マーケティングと営業のデータが完全に分断していた** ― MAは契約していたものの複雑すぎて誰も使えず、実質的に放置状態。代わりに別のメール配信ツールを使っていたため、マーケティングのデータと営業のデータがまったくつながっていなかった。
2. **「使えないツールにお金を払い続けている」状態** ― Salesforceのコストが重く、契約満了を機に乗せ替えてコストを下げたい。
3. **非エンジニアでも回せる仕組みにしたい** ― 専門知識がないと設定も運用もできない状態から脱却し、現場の営業メンバーが自分たちで使えるCRMにしたい。
4. **契約満了というタイムリミット** ― Salesforceの契約が切れるまでに、移行を完了させなければならない明確な締め切りがあった。

## 支援内容

約2ヶ月という限られた期間のなか、データを1件も失わずに移しきることを最優先に支援しました。

### 標準ツールでは届かない規模を、完全カスタム実装で

55万件超というデータ規模は、市販の移行ツールでは対応しきれません。そのため、お客様のデータ構造に合わせた**完全カスタム実装**で移行を設計しました。

### 2系統に分かれたメール履歴を、重複ゼロで統合

メール履歴は2つの仕組みに分散しており、そのまま移すと重複が大量に発生する状態でした。これを整理し、**42万件超のメール履歴を重複ゼロ**で移行。営業とサポートの履歴が一本に揃いました。

### 内部コードと表示名のズレを、全項目で変換

Salesforce内部では、画面に表示される名称と、システムが裏側で持っているコードが食い違っている箇所が数多くありました。これを**全項目で正しい表示名に変換**し、移行後に「中身が文字化け・記号化けして読めない」という事故を防ぎました。

### 最難関だったMRRデータの移行

今回いちばんの難所が、毎月の売上（MRR）データでした。Salesforce側では「商談の明細」という形で管理されていた売上を、HubSpot側の「月次の売上レコード」へと正しく組み替える必要がありました。

ここはそのまま移すことができないため、**Salesforceの商談明細をHubSpotの月次売上レコードに変換する独自の設計**を構築。移行後には独自の数値検証を行い、**31,408件・34.8億円分の売上データが完全一致していることを確認**しました。1件の欠落もありませんでした。

### 営業規律をHubSpotで再現

「このステージに進むには、この情報の入力が必須」という、これまで運用してきた営業のルールもHubSpot上で再現。ツールを変えても、現場の規律が崩れないようにしました。

## 成果（After）

- **55万件超のデータを、1件も失わずに移行完了** ― 契約満了のタイムリミットに間に合わせつつ、データの欠落ゼロを実現。
- **34.8億円分の売上データを完全一致で移管** ― 経営の根幹である売上データを、独自検証のうえで1件も失わずに移しきった。
- **分断していたマーケティングと営業が一つの基盤に統合** ― これまでバラバラだったマーケデータと営業データが同じHubSpot上に集約され、見込み客から受注までを一気通貫で追えるようになった。
- **誰も使えなかったMAから、現場が自走できるCRMへ** ― 「複雑すぎて放置」だった状態を脱し、非エンジニアの営業メンバーが自分たちで運用できる仕組みになった。
- **コスト削減を実現** ― Salesforceからの乗せ替えにより、ランニングコストを圧縮。

## なぜHarekaだったのか

55万件超・34.8億円分のデータを1件も失わずに移すには、SalesforceとHubSpotの両方を深く理解し、市販ツールに頼らず独自の移行設計を組める力が欠かせません。「とにかく移す」だけなら誰でもできますが、**売上データを正しく組み替え、移行後に完全一致まで検証しきる**ところまでやり切れるかどうかが分かれ目です。

さらにHarekaは、ツールを設定して終わりにはしません。**非エンジニアの現場が自分たちで使いこなせる状態**をゴールに据え、営業の規律ごとHubSpotに移す。HubSpot Japanで200社以上を支援してきた現場知識と、代表が全案件を一貫して担当する体制が、このプロジェクトを支えました。
